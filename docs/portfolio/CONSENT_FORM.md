# Recording consent form (blank)

One form per musician, signed **before** recording. Print it, read it together,
tick each line yes or no, sign two copies (one each). The items follow
`docs/data/consent/README.md`.

After signing: the paper and any scan stay in Khalid's private storage and
never enter this repository. Only a text line goes into the index in
`docs/data/consent/README.md`.

The Somali text is a draft by the assistant. Khalid checks it before anyone
signs; if the two languages disagree, the version the musician read decides.

---
