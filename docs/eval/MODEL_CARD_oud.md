# Model card — `oud` adapter (QaraamiGen)

**Artifact:** LoRA adapter `runs/oud_lora_r16_nodrop_20260809/ckpt_step_0500` (PEFT format, 25 MB, ~6.29 M trainable parameters). Not distributed; served locally by `services/musicgen-api`.

## Base model
`facebook/musicgen-small` (MusicGen, 300 M decoder + T5 text encoder + EnCodec 32 kHz, 4 codebooks @ 50 Hz). Weights from Hugging Face, loaded from the local cache; unchanged. The adapter adds rank-16 LoRA (α = 32, dropout 0.05) on the decoder's self- and cross-attention `q_proj/k_proj/v_proj/out_proj` (192 sites).

## Training data — described, not distributed
A privately shared collection of oud (*kaban*)-led Somali qaraami recordings: 28 unique songs after byte-level de-duplication (~8 h), performers deliberately unlisted. Processed to 1,921 fifteen-second clips (32 kHz mono, −14 LUFS): train 1,512 · val 133 · test 276, **song-level splits** by sha256 so no song appears in two splits. Captions are measured (librosa tempo) and detected (pentatonic tonic): *"Somali qaraami led by the oud (kaban), moderate at 100 BPM, pentatonic melody rooted on A, intimate home recording."*

**Rights.** Rights remain with the performers and holders. The source audio, the processed clips and the EnCodec tokens are not distributed and never enter git or any public URL; only the adapter's *outputs* are shown. See `docs/DATA_PROVENANCE.md` §4.

## Training
Fixed harness (`apps/ai-service/scripts/phase2_train.py`, 2026-08-09): the 37 functional-dropout attributes of the HF MusicGen decoder zeroed so train ≡ eval path. fp32 on Apple MPS (M1, 16 GB), batch 1 × grad-accum 4, lr 1e-4 cosine with 100 warm-up steps, AdamW, grad-clip 1.0, gradient checkpointing, 1,000 steps (~3 h at 9 s/step), seed 42. Precomputed EnCodec tokens with delay-pattern labels.

## Metrics (held-out, song-level)
| | base | adapter (step 500) |
| --- | --- | --- |
| validation token CE (64 clips) | 4.5132 | **4.4785** |
| test token CE (128 clips, unseen songs) | 2.6302 | **2.6092** |
| PCS mean, 8 paired 10-s prompts (2026-09-04 re-score) | 0.932 | 0.900 |
| voiced fraction (trackable melody) | 0.329 | **0.538** |
| median |tuning offset| | 4.6 c | 25.8 c |

Every checkpoint beat base on validation; mild late-run overfit after step 500. Real held-out oud clips: PCS 0.914, voiced 0.435. **Listening gate passed** (owner A/B on `data/oud_ab_listening`, eight pairs, same seeds both sides). PCS at n = 8 is inside scorer noise (a single tuning-offset flip moved it 0.942 → 0.900 between torch builds); the robust effect is +64 % voiced fraction and a learned ~25 c tape offset.

## Intended use
Research demonstration of adapting a general music model to an under-represented oral tradition; the base-vs-adapter comparison in the local demo; qualitative material for the ISMIR paper and an application portfolio. Every generation is labelled *"Generated by facebook/musicgen-small with the 'oud' LoRA adapter, fine-tuned on the privately shared oud (kaban) qaraami collection … Source recordings are not distributed."*

## Out of scope / limitations
- 10–30 s clips from MusicGen-**small**; no long-form structure.
- Trained on one collection of one instrument family; not a model of Somali music at large.
- Token-CE margins are small (0.5–3 %); listening is the arbiter.
- Not for commercial release, not for imitating identifiable performers, not for any use that would present model output as archival recordings.
