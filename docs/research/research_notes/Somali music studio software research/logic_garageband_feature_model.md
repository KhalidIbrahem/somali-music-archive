# Feature model and UI anatomy of Logic Pro (Mac, iPad), GarageBand (Mac, iOS) and browser DAWs, 2024–2026

Research notes compiled 2026-11-07 for a browser-studio feature map and layout spec. Method and provenance: Apple's own user-guide pages were downloaded in full (Logic Pro User Guide for Mac, version selector "Logic Pro for Mac 13.0"; ~200 article bodies read; the guide's table of contents has 2,002 entries) together with Apple's Logic Pro 11 release-notes page and the May 2024 newsroom post. The GarageBand (Mac 10.4.x, iOS 2.3.x), Logic Pro for iPad (3.x) and web-DAW sections consolidate notes written by three parallel sub-researchers from Apple's GarageBand and Logic-for-iPad guides, Apple release notes, vendor documentation and dated trade coverage; their citations are carried through unchanged and were spot-checked against freshly downloaded Apple pages (for example, no Apple GarageBand or Logic-for-iPad page enumerates the Keyboard scale list; both only say "tap the Scale button, then tap the scale"). The planned fourth sub-researcher (visual design, collaboration) was cut off by a usage limit before producing anything; those two questions are answered below from the Apple pages and the web-DAW notes, with explicit gaps. Web search ran out mid-task, so some 2024–2026 reviews named in the brief (MacStories, Production Expert, MusicRadar bodies) were not reachable; where a fact rests on a search-result summary rather than a fetched page, it is marked.

## 1. Version baseline: what "as of 2025–2026" means for each product

### Takeaway
Logic Pro for Mac went 11.0 (13 May 2024) → 11.1 (Nov 2024) → 11.2 (May 2025) → 12.0 (28 Jan 2026, with the Apple Creator Studio subscription) → 12.3 → 13.0 (Nov 2026, "Liquid Glass", unified Browser, intelligent assistant beta); Logic Pro for iPad is at 3.4 (29 Sep 2026) and is sold only inside Apple Creator Studio for new customers; GarageBand is at 10.4.15 (Mac) and 2.3.19/2.3.20 (iOS) with no new creative features since 2020–21.

### Inferences
- "Logic-Pro-like" in late 2026 means Logic Pro 13's model: one unified Browser instead of Library + Loop Browser, one consolidated inspector, in-place Play Surface, Session Players driven by a Chord track, and heavyweight ML (stem separation, natural-language search, an agentic assistant) presented as ordinary commands but gated to Apple silicon and a subscription.
- Apple now versions Mac (13.x) and iPad (3.x) independently; the iPad did not get a same-day 13.0 counterpart, so the iPad guide (3.3/3.4) is the right source for tablet anatomy.

### Gaps
- Apple's release notes carry no dates; 12.1/12.2/12.4 dates and whether 12.4 exists as Apple names it (a third-party post says 12.4 shipped 29 Sep 2026; the guide selector shows 12.3 as the last 12.x) are unverified from Apple.
- The Logic Pro 13 newsroom post itself was not fetched (search budget exhausted); announcement-day details rest on a search summary.

## 2. Logic Pro for Mac: main window, control bar, toolbar, LCD/Display, transport, cycle, metronome

### Takeaway
The main window is one resizable frame whose control bar (top) toggles every other area; the LCD/Display in the centre has five modes (Beats & Project, Beats & Time, Beats, Time, Custom) and doubles as the editor for tempo, key and time signature; the toolbar is an optional second row; the cycle area is a yellow strip in the upper ruler; nearly every control-bar function has a single-key default command (C cycle, K click, Shift-K count-in, Space play/stop, R record).

### Cited Findings
- Main-window areas, verbatim: "Tracks area: Where you record audio and MIDI regions…"; "Control bar: Includes the transport controls… buttons to show and hide the different areas of Logic Pro, and buttons for other frequently used commands. You can customize the control bar"; "Toolbar: Contains additional buttons and controls for the Tracks area… You can show and hide the toolbar to optimize available screen space"; "Browser: Where you find and preview patches, loops, presets, samples…"; "Inspector: Shows parameters for selected regions, tracks, and other items"; "Smart Controls"; "Mixer"; "Editors: … Audio Track Editor, Piano Roll Editor, Score Editor, Step Editor, and Audio File Editor"; "List Editors: … MIDI events, markers, tempo, and time signature events numerically"; "Note Pad"; "Project Files: … Project Audio browser … All Files browser". "You can show or hide different areas as part of the main window. Some can also be opened as separate, movable windows. You can also open multiple instances of the main window." Window > Open Main Window = Command-1 — [Source](https://support.apple.com/guide/logicpro/main-window-interface-lgcpe9cc403a/mac)
- Control bar: "In the center of the control bar is the LCD, which shows the playhead position and the project tempo, key, and time signature." Customisation: show/hide the whole bar; show the Master Volume slider, the output meter, or neither ("to the right of the Metronome and Count-in buttons"); show/hide individual buttons via Control-click > "Customize Control Bar and Display" (Apply Defaults / Save As Default / Revert); open "giant beats display" or "giant time display" floating windows; SMPTE view offset; time, tempo and clock formats in Settings > View > General ("Display Time as": With Bits / Without Bits / With Quarter Frames / Feet Frames 35 mm / 16 mm / With Milliseconds / With Samples / With Frames and Samples; "Display Tempo as": BPM to four decimals / BPM without decimals / Frames Per Click with Eighths / with Decimals) — [Source](https://support.apple.com/guide/logicpro/customize-the-control-bar-lgcp5bdd6d9d/mac)
- Display modes: "Beats & Project: Displays the time format in bars and beats, and displays project properties (tempo, key, and time signature). Beats & Time: … both musical and absolute time formats. Beats … Time … Custom: Displays the playhead position in both musical and absolute time formats, with additional information, including the tempo, key, project end, left and right locator positions, MIDI In and MIDI Out status, CPU usage and HD throughput." — [Source](https://support.apple.com/guide/logicpro/change-the-display-mode-in-logic-pro-for-mac-lgcp127f51bc/mac)
- Default transport set: "Rewind, Forward, Stop, Play, and Record buttons to the left of the LCD, and the Cycle, Replace, Autopunch, Solo, and Click (Metronome) buttons to the right of the LCD." Rewind/Forward move one bar, click-and-hold to fast-wind, drag to scrub, Command-click to previous/next marker; Stop clicked twice goes to project start or left locator; Record = Asterisk. Additional buttons: Go to Beginning, Go to Position, Go to Left/Right Locator, Go to Selection Start, Play from Beginning / Left Window Edge / Left Locator / Right Locator / Selection, Pause, Flashback Capture ("Captures the most recent performance, even if Logic Pro was not in record mode") — [Source](https://support.apple.com/guide/logicpro/control-playback-with-the-transport-buttons-lgcp0b07c0c9/mac)
- Shortcut menus on Stop (Stop and Go to Left Locator / Last Locate Position; Jump Between Marquee, Cycle, Selected Region or Last Locate Position and Project Start) and Play (Play From Marquee Selection / Cycle / Selected Region / Last Locate Position) — [Source](https://support.apple.com/guide/logicpro/use-transport-shortcut-menus-lgcpc2e497bd/mac)
- Playhead: click the lower half of the ruler; Shift-click empty Tracks area; drag or double-click LCD position digits; Option-click a marker; "The LCD can display the playhead position in Beats or Time format, or both" — [Source](https://support.apple.com/guide/logicpro/set-the-playhead-position-lgcp0f34ca7a/mac)
- Cycle: "When Cycle mode is on, the cycle area is displayed as a yellow strip in the upper part of the ruler (or in the center, when the secondary ruler is visible)"; locators grey when off; toggle with the Cycle button or C; drag in the upper ruler to set; Shift-click trims; Command-click makes a skip cycle; Control-click Cycle > Auto Set Locators by Marquee / Region / Note / Marker-Chord selection; Command-U sets locators by selection; Shift-Command-. / , move the cycle by its length; the Custom LCD shows left/right locators (or left + length) — [Source](https://support.apple.com/guide/logicpro/use-the-cycle-area-lgcp59e41e86/mac)
- Autopunch: "indicated by a red stripe in the middle third of the ruler"; Option-Command-click the ruler; Quick Punch-In on by default; Record Toggle key command; Marquee selection can engage autopunch — [Source](https://support.apple.com/guide/logicpro/punch-in-and-out-of-audio-recordings-lgcpb19bfd0d/mac)
- Metronome: Metronome button or K; Control-click for Simple Mode / Click While Recording (purple outline) / Only During Count-In / Click While Playing (purple); Count-in button or Shift-K; count-in length under Record > Count-in or Project Settings > Recording; Klopfgeist on a hidden "Click" channel strip that is solo-safe; polyphonic clicks per Bar/Group/Beat/Division — [Source](https://support.apple.com/guide/logicpro/use-the-metronome-lgcp0534986f/mac); [Source](https://support.apple.com/guide/logicpro/metronome-project-settings-lgcpe1d6118e/mac)
- Project properties set in the LCD (Beats & Project mode): tempo "ranging from 5 to 990 bpm", also Tempo List/Tempo track/Tap Tempo key command; key signature defaults to C major, chosen from a pop-up; time signature pop-up plus "Custom"; the division value "is normally set to 1/16 notes, but can range in value from 1/4 to 1/192 notes" and defines the grid — [Source](https://support.apple.com/guide/logicpro/set-the-project-tempo-lgcpce0ff024/mac); [Source](https://support.apple.com/guide/logicpro/set-the-project-key-signature-lgcp42b42603/mac); [Source](https://support.apple.com/guide/logicpro/set-the-project-time-signature-lgcpce102b95/mac)
- Toolbar: shown with the Toolbar button in the control bar; Control-click > Customize Toolbar; Save As Default / Restore Defaults — [Source](https://support.apple.com/guide/logicpro/customize-the-toolbar-lgcp0591f74d/mac)
- Pointer shortcuts on the control bar: Command-click Forward/Rewind for next/previous marker; double-click the Performance Meter in the Custom LCD for a standalone CPU window (Command / Control-Option-Command for larger sizes); Option-click Solo = Solo Lock — [Source](https://support.apple.com/guide/logicpro/control-bar-lgcp2a46feca/mac)
- Project Chooser (File > New from Template, Command-N) sidebar: "New Project", "Recent", "Live Loops Grids", "Project Templates", "My Templates"; Details triangle exposes Use musical grid, Use Flex Time for imported audio, Tempo (slider, field, Tap Tempo), Key Signature, Time Signature, Input/Output Device, Sample Rate, Frame Rate, Spatial Audio, Surround Format; "Get More Sounds" opens the Sound Library; Shift-Command-N creates an empty default project via the New Tracks dialog — [Source](https://support.apple.com/guide/logicpro/create-projects-lgcpce0f09d9/mac)

### Inferences
- The control bar is the window's navigation: a browser studio should give every pane a toggle button in a fixed top bar, keep transport + LCD centred, and make the LCD both a readout and an editor (drag digits, double-click to type).
- Logic treats the ruler as three stacked hit zones (upper = cycle/skip, middle = autopunch, lower = playhead). Reproducing those zones is what makes a timeline "feel like Logic".

### Gaps
- Apple publishes no pixel heights for the control bar, toolbar or LCD, nor the default button order beyond the transport description.

## 3. Logic Pro for Mac: Tracks area, ruler, track headers, regions, global tracks, markers, zoom, snap/drag, tools, colours

### Takeaway
The Tracks area is "the primary workspace": a local menu bar (tools, automation/Flex toggles, Catch, Snap and Drag menus, waveform and X/Y zoom sliders), a ruler in bars/beats or time, resizable track headers with configurable components, rounded-rectangle regions colour-coded by type, and up to seven global tracks (Arrangement, Marker, Signature and Tempo visible by default; Movie, Chord and Beat Mapping optional) below the ruler.

### Cited Findings
- Elements: "Tracks area menu bar: Contains local Tracks area menus as well as tool menus, controls for showing track automation and Flex edits, a Catch Playhead button, Snap and Drag pop-up menus, a Waveform Zoom button, and Zoom sliders. Ruler: Shows divisions of time, either in bars and beats or in hours, minutes, and seconds… Track headers: Each track has a header that shows the track name and icon, and includes controls for muting and soloing the track, enabling the track for recording… Workspace: All audio and MIDI regions appear on horizontal lanes called tracks… Playhead: The thin vertical line extending from the top to bottom of the Tracks area" — [Source](https://support.apple.com/guide/logicpro/tracks-area-interface-lgcpe9cc3f60/mac)
- Track types: audio, software instrument (default region type MIDI, pattern or Session Player chosen in the New Tracks dialog), external MIDI, folder; each track maps to a Mixer channel strip; global tracks "appear below the ruler in the Tracks area and in linear editors" — [Source](https://support.apple.com/guide/logicpro/tracks-overview-lgcpd9638760/mac)
- Track header controls: default "Mute, Solo, Record Enable, and Input Monitoring buttons on audio and instrument tracks"; optional "On/Off and Hide buttons, and Track Number and Color Bars options"; Configure Track Header popover (Option-T) with Buttons, Controls (volume, pan or a send level), Additional Name Column, Control Surface Bars, Track Numbers, Color Bars, Groove Track, Track Icons, Track Alternatives; "Horizontally resize all track headers" by dragging the divider between headers and tracks; Store/Apply User Configuration — [Source](https://support.apple.com/guide/logicpro/track-header-overview-lgcpe53c68af/mac)
- Track alternatives: per-track "playlists" (A, B, C…) sharing the channel strip; Track Alternatives pop-up in the header; Show Inactive shows them as extra lanes; comp by copying between alternatives — [Source](https://support.apple.com/guide/logicpro/use-track-alternatives-lgcp002c4e63/mac)
- Regions "appear as rounded rectangles in the Tracks area"; types: audio, MIDI, pattern (Step Sequencer), Session Player; operations include select, cut/copy/paste, move, loop, shift playback position, resize, time stretch, split/join, demix MIDI, aliases, colour, convert to sampler, Region inspector parameters — [Source](https://support.apple.com/guide/logicpro/regions-overview-lgcpf7c0d0bb/mac)
- Loop a region by dragging its upper-right edge (notches mark repetitions) or press L for continuous loop; Edit > Convert > Loops to Regions — [Source](https://support.apple.com/guide/logicpro/loop-regions-lgcpf7c0e0db/mac)
- Loop and patch colours: audio loops blue, MIDI loops green, Session Player loops yellow, pattern loops violet; one-shots blue; audio patches blue, aux patches yellow, output patches pink, instrument patches green — [Source](https://support.apple.com/guide/logicpro/loops-and-one-shots-overview-lgcpa039bc05/mac); [Source](https://support.apple.com/guide/logicpro/patches-overview-lgcpa8833ba0/mac)
- Colours: "Newly recorded or added regions use the color of the channel strip"; regions can be coloured individually only when Settings > View > Tracks > Region Color is "Individual" (not "As Track Color"); Option-C shows the Color palette; Functions > Color Regions/Cells by Track Color; track colours default to track type and show when Color Bars are enabled; Track > Assign Track Color (Option-C) — [Source](https://support.apple.com/guide/logicpro/change-the-color-of-regions-lgcpf7c0db8c/mac); [Source](https://support.apple.com/guide/logicpro/change-track-colors-lgcp7a5a5423/mac)
- Global tracks: Arrangement, Movie, Tempo, Chord, Marker, Signature, Beat Mapping; "By default, the Arrangement, Marker, Signature, and Tempo tracks are visible when you show the global tracks"; show with G or the Global Tracks button above the headers; Configure Global Tracks (Option-G) per window; "Show Single Global Track" (Control-Option-Command-G); Protect buttons; the Signature track shows one combined lane when reduced in height and two lanes (time, key) at full height — [Source](https://support.apple.com/guide/logicpro/global-tracks-overview-lgcp4994bead/mac); [Source](https://support.apple.com/guide/logicpro/show-and-hide-global-tracks-lgcpd0e8ce94/mac); [Source](https://support.apple.com/guide/logicpro/time-and-key-signature-overview-lgcp6409cfb7/mac)
- Global-track key commands: Secondary Ruler Control-Option-Shift-R; Scroll in Play Control-`; Show/Hide Arrangement Shift-Command-A, Marker Shift-Command-K, Movie Shift-Command-O, Tempo Shift-Command-T, Chord Shift-Command-C, Beat Mapping Shift-Command-B; Marker track only = Apostrophe; Transpose Chords ±1 semitone Option-Shift-Command-Up/Down — [Source](https://support.apple.com/guide/logicpro/views-showing-time-ruler-lgcp267f63a1/mac)
- Markers: Marker track (rectangles, editable length/text/colour), Marker List (name, bar position, length; Marker Text area; Marker Set menu), Marker Text window, and markers on the ruler when global tracks are hidden; Create Marker Option-', without rounding Control-Option-', from region/marquee Option-Shift-'; drag the cycle area to the Marker track; Option-double-click an arrangement marker — [Source](https://support.apple.com/guide/logicpro/markers-overview-lgcp0ec9fc09/mac); [Source](https://support.apple.com/guide/logicpro/add-markers-lgcp564d6a94/mac); [Source](https://support.apple.com/guide/logicpro/marker-list-interface-lgcp31f1cf25/mac)
- Tempo track: tempo points; drag the scale's max/min to change range; available in Tracks area, Piano Roll, Step and Score editors; tempo curve colours under Smart Tempo: blue (followed), orange (defined by new recording), red (changing during a drag) — [Source](https://support.apple.com/guide/logicpro/tempo-track-overview-lgcpc0ba44af/mac); [Source](https://support.apple.com/guide/logicpro/smart-tempo-overview-lgcp9281e70c/mac)
- Ruler: bars/beats when "Use musical grid" is on, else minutes/seconds; alignment guides; Secondary Ruler from the View menu; Smart Snap units follow the grid — [Source](https://support.apple.com/guide/logicpro/position-items-using-the-ruler-lgcpf7c0ec53/mac)
- Snap: default "Snap Regions to Absolute Value"; values Smart, Bar, Beat, Division, Ticks (1/3840 beat), Frames, Quarter Frames, Samples, Off; "Snap Regions to Relative Value"; View > Grid Lines, with the 12.3 Tracks View setting for grid lines over or under regions; Control-drag overrides the grid, Control-Shift-drag switches to ticks/samples — [Source](https://support.apple.com/guide/logicpro/snap-items-to-the-grid-lgcpf7c0f66a/mac)
- Drag modes: Overlap, No Overlap, X-Fade, Shuffle R, Shuffle L — [Source](https://support.apple.com/guide/logicpro/control-positioning-with-drag-modes-lgcpf7c0a2ec/mac)
- Zoom: Horizontal and Vertical Zoom sliders; Vertical/Horizontal Auto Zoom buttons (blue when on); Option-drag the playhead top in the ruler; pinch; Zoom tool (Control-Option); Save/Recall Zoom 1–3; per-track zoom by dragging a track's bottom-left corner (Command for all, Shift to reset); Control-Z "Zoom Focused Track"; Waveform Zoom button; Command-Arrow keys zoom in all windows — [Source](https://support.apple.com/guide/logicpro/zoom-windows-lgcp5cbf2096/mac); [Source](https://support.apple.com/guide/logicpro/automatically-zoom-the-tracks-area-lgcpf0ff2737/mac); [Source](https://support.apple.com/guide/logicpro/zoom-tracks-lgcpc79f5bcd/mac); [Source](https://support.apple.com/guide/logicpro/scroll-and-zoom-in-the-tracks-area-lgcpf7c0b924/mac)
- Tools: Left-click and Command-click Tool menus (plus right mouse button); T opens the Tool menu; common tools Pointer, Pencil, Eraser, Text, Scissors, Join, Solo, Mute, Zoom, Fade, Automation Select, Automation Curve, Marquee, Flex, Slip, Rotate; area-specific Finger, Quantize, Velocity, Brush, Vibrato, Volume, Move, Camera/Layout/Resize/Voice Separation, Line, Gain — [Source](https://support.apple.com/guide/logicpro/tools-overview-lgcp9b92f74c/mac); [Source](https://support.apple.com/guide/logicpro/common-tools-lgcp8b7459e4/mac)
- Catch: Catch button per area; Settings > General > Catch ("Catch when starting playback", "Catch when moving playhead", content catch); Scroll in Play keeps the playhead centred — [Source](https://support.apple.com/guide/logicpro/control-windows-using-catch-modes-lgcp5cbf1727/mac)
- Key focus: "Inside a window, the area with key focus (for example, the Tracks area) is bordered by a blue frame"; Tab / Shift-Tab cycle areas; Command-W closes; Option-click close closes all — [Source](https://support.apple.com/guide/logicpro/open-and-close-windows-lgcp5cbf18ca/mac)
- Takes: cycle recording creates a take folder after the second pass; Quick Swipe Comping (Option-Q) for audio take folders; take folders open with disclosure arrow, double-click or Control-F — [Source](https://support.apple.com/guide/logicpro/record-multiple-audio-takes-lgcpb19806af/mac); [Source](https://support.apple.com/guide/logicpro/comping-overview-lgcp317d758e/mac)
- Track stacks: folder stacks (VCA-style master, no patches/Smart Controls on the main track) and summing stacks (bus to an aux; patches and Smart Controls on the main track; MIDI on the main track plays all instrument subtracks); the Mixer mirrors the stack disclosure unless View > Follow Track Stacks is off (13.0) — [Source](https://support.apple.com/guide/logicpro/track-stacks-overview-lgcp9bc4b63d/mac); [Source](https://support.apple.com/guide/logicpro/track-stacks-and-the-mixer-lgcp1af4dc6b/mac)

### Inferences
- Logic's arrange pane is a fixed grammar: header column (resizable, configurable), ruler with stacked hit zones, global lanes, region lanes, playhead; everything else is optional chrome. A browser studio that keeps this grammar and its colour semantics (type colour on regions, track colour bar, yellow cycle, red punch, blue focus frame) will read as Logic-class even before features match.
- Snap/Drag/Catch as three small pop-ups in the local menu bar is the density pattern to copy; GarageBand hides all three.

### Gaps
- Default track-header width, default track height, ruler height and region corner radius are not published; only behaviours (resizable, zoomable) are.

## 12. Logic Pro for iPad (2.x–3.4): anatomy, Browser, Plug-in Tiles, Mixer, Play Surfaces, and how the UI condenses

### Takeaway
Logic for iPad is Logic's layout re-expressed as three slots: a top control bar, a bottom "view control bar" of seven toggles (Browser, Inspector, Fader | Editors, Plug-ins, Mixer | Play Surfaces), a centre canvas (Tracks or Live Loops, never both), one exclusive left slot and a vertically resizable bottom stack; plug-ins never float (tile strip → full-width Details view with sibling mini tiles); edit tools are modes with long-press as momentary; every number opens a wheel/keypad sheet.

### Inferences (lessons for phone/tablet widths)
- Model the screen as three slots: exclusive left slot (browser | inspector | fader), exclusive centre canvas (arrange | grid), bottom stack of collapsible, resizable, maximisable areas (editor, plug-in chain, mixer, play surface), plus a one-gesture "collapse all".
- At 820–1024 px, run the iPad layout nearly 1:1 (seven icon toggles in a bottom bar; side pane ≈ 300–360 px; bottom areas with drag handles; portrait → mixer/Details full height). Treat 50 % Split View (~500–600 px) as a real breakpoint where the side slot becomes a sheet.
- At ≈390 px, promote the seven toggles to full-screen tabs (Arrange, Library, Track, Chain, Mixer, Play), use the Details-view breadcrumb (back button + sibling mini tiles) for plug-ins and the "one mini track above the mixer + Select Track menu" pattern for context; keep transport in a fixed top bar with the LCD reduced to position only.
- No floating windows; modes not modifiers (visible edit-mode row with long-press momentary, Select toggle swaps the row for Selection/Functions menus); every numeric field opens a sheet with wheel and keypad; 44×44 CSS px targets; disambiguate scroll vs drag with select-first or handles.

### Gaps
- Apple publishes no pt/px dimensions, breakpoints or per-model layout differences; width numbers above are design inferences. Whether Editors, Plug-ins and Mixer are strictly mutually exclusive is not stated.

### Inferences (feature-map and layout-spec inputs)
1. Fixed top bar = pane toggles + transport + an editable LCD with at least Beats & Project / Time / Custom modes; optional second toolbar row.
2. Arrange pane = resizable header column (name, icon, M/S/R/I, colour bar, optional volume/pan), ruler with upper (cycle) / middle (punch) / lower (playhead) zones and a secondary ruler, default-visible global lanes (Arrangement, Marker, Signature, Tempo) plus a Chord/Scale lane, rounded regions coloured by type with loop notches, Snap/Drag/Catch pop-ups, X/Y zoom sliders and auto-zoom.
3. One left slot: Browser (search modes: name, tag chips, "sounds like", similar; list / table / column layouts; preview per row; Link to Selection; Replace mode) or Inspector (selection parameters + the selected track's channel strip).
4. One bottom slot chosen by selection: Audio editor, Piano Roll (velocity colour, letter-key step input A W S E D F T G Y H U J), Score/notation (MusicXML in/out), Step Sequencer, accompaniment editor (Complexity / Intensity / Fills / Swing + style), Play Surface (keyboard, chord strips, pads; scale lock with root + scale; side controls), Mixer (full strip per Logic's component list, Single/Tracks/All filters), Smart-Controls-style macro panel; pop-out as the escape hatch on desktop only.
5. Modes not modifiers on touch (Trim / Loop / Split / Stretch; Pencil / Brush / Velocity; long-press momentary; Select toggle), numeric sheets with wheel + keypad, 44 px targets, three-slot collapse at ≈500–600 px, full-screen tabs at ≈390 px.
6. Shortcut set: Space, R, C, K, Shift-K, S, M, L, Q, A, G, E, B, I, X, Y, P, N, O, D, T, Z, arrows, Command-Z/Shift-Command-Z; plus a searchable, filterable, importable key-command editor and an in-app overlay.
7. Musical data: project key/time signature/tempo editable in the LCD; a Chord lane that generators, scale locks and notation read; a scale model that goes beyond Apple's 12-TET presets (per-degree cent offsets, quarter-tone bends) for qaraami repertoire.
8. Learn/play: GarageBand-style lesson view (synced notation + instrument animation + media, loopable sections, half-speed, per-note green/red/yellow grading with a percentage and history) merged with Soundslice's click-to-seek, loop-snap and speed training.
