## Method

Inventory: `apps/ai-service/scripts/ahmed_extract.py` (ffprobe metadata, full-file sha256 as file identity, silence fraction over 50 ms frames of a 16 kHz mono decode below -50 dBFS, role guess from location and name with mixdown words mix/mixed/mixdown/final/finalized/last/bounce/bip/mul; exclusion rules: overview_cache, unreadable, apple_loop (every .caf file plus Apple loop names of the form `<Loop words> NN`), silent (silence fraction > 0.95 or duration < 3 s), duplicate (same sha256 as an earlier file in canonical order ahmed_collection > garageband > logic, then project, name, mtime; the first copy survives with `also_in`)). Rights flag `third_party_suspect` (reasons import, mixed, xml): a track-numbered import under Media/Audio Files, a `_mixed` name, an `xml` imported instrumental base; these rows keep their content label and stay in every table above, so they must be excluded from training sets until their rights are settled.

Classification: `apps/ai-service/scripts/ahmed_classify.py`. Features per file over up to 2 evenly spaced 30 s windows: MERT-v1-95M last-layer mean embedding (768-d), Silero VAD vocal_fraction, HPSS percussive_ratio and onset strength, torchcrepe voiced_fraction and PCS, spectral flatness. Seed labels from these rules (a file matching several rules is a seed conflict and stays unclassified):

- `oud`: name has kaban/oud, or source_group ahmed_collection with vocal_fraction < 0.06 and no "mixed" in the name
- `voice`: name has cod/codd/vocal/vocals/voice (cod also as a suffix) and (vocal_fraction >= 0.25, or voiced_fraction >= 0.6 with percussive_ratio < 0.25); or, without a name hint, vocal_fraction >= 0.5 with percussive_ratio < 0.25 on a non-mixdown role
- `drums`: name has beat/beeat/beats/drum/drums/tarax/sacab/kick/shaker/percussion, or percussive_ratio >= 0.6 with voiced_fraction < 0.2
- `synth`: name has synth/xml/pad/pads/string/strings/piano/keys, or spectral_flatness_mean >= 0.2 on a .caf file
- `full_mix`: role_guess is mixdown (Output/, Bounces/, "Output 1-2" or a name with mix/mixed/mixdown/final/finalized/last/bounce/bip/mul)
- `rap`: name (or the project, for generic take names) has rap/tictok/tiktok/dj; takes precedence over every other rule
- `other`: never seeded; assigned to files whose features could not be computed

Model: LogisticRegression(C=1, class_weight=balanced) on MERT-v1-95M last layer (768, unit norm x sqrt(768)) + standardised ['vocal_fraction', 'percussive_ratio', 'onset_strength_mean', 'voiced_fraction', 'pcs', 'spectral_flatness_mean'] + pcs_missing. Seeds: 490 of 1003 rows (drums 42, full_mix 292, oud 25, rap 26, synth 7, voice 98).
Cross-validation: stratified 5-fold on the seeds, accuracy 0.786, balanced accuracy 0.565; per class: drums F1 0.48 (n=42), full_mix F1 0.87 (n=292), oud F1 0.58 (n=25), rap F1 0.43 (n=26), synth F1 0.13 (n=7), voice F1 0.86 (n=98), macro avg F1 0.56 (n=490), weighted avg F1 0.79 (n=490).
Prediction: predicted_content = argmax over every processed row; a row is unclassified when content_prob < 0.6 or on a seed conflict, and its `content` is then null (only confident rows carry a label). Rows processed 1003, usable 1003, unclassified 121, seed conflicts 34; device mps, 4.2 s.

Song grouping: `ahmed_classify.song_group()` NFKD-folds the project / bundle / file name to ASCII lowercase, drops numbers, genre words, Somali function words and take/variant/role tags, keeps the first remaining word with doubled vowels collapsed and `ey` -> `ay`, then applies the aliases galdodob -> galdogob, galdodog -> galdogob, saynabay -> sanabay, xajinta -> xajin, dilimalr -> dilimale, hinasuhu -> zaki, cana -> canamal, sadex -> canamal, 365 -> canamal. Generic bundle names (My Song N, untitled, AUDIO-…, a bare number) keep their digits. `assign_song_groups()` keys a titled file by its own title and a generic take by its project, then merges keys when a title names its project's song (a shared content word) or the project is generic, and when two projects hold a byte-identical recorded take (`#NN` .aif, a "Save As" lineage). Any other shared file (imports, drum stems, stale Output.aif copies) does not merge its hosts: a titled one keeps its title's group, a generic one takes the majority group of its hosts and is flagged `group_ambiguous` when they disagree. The chosen mixdown per project is its longest non-excluded mixdown-role file.

Thresholds: OUD_VAD_MAX = 0.06, VOICE_VAD_MIN = 0.25, VOICE_VAD_STRONG = 0.5, VOICE_VOICED_MIN = 0.6, VOICE_PERC_MAX = 0.25, DRUMS_PERC_MIN = 0.6, DRUMS_VOICED_MAX = 0.2, SYNTH_FLATNESS_MIN = 0.2, PROB_MIN = 0.6.
